# Satellite_Image_Classification
A repo for deeplearning CSSE416-1 project Satellite_Image_Classification

Needed dependencies: copy, torch, tqdm, numpy, pandas, rasterio, sklean, plotly, IPython, torchvision, matplotlib, torchmetrics, kagglehub

Dependencies that likely are not already installed: rasterio, torchmetrics, kagglehub

Can be downloaded via:
pip install rasterio
pip install torchmetrics
pip install kagglehub

Dataset is the Eurosat dataset. The import script can be found at datasetimport.py
